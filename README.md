# Tesorería · Plantel Superior de Caballeros

Versión instalable de la app de tesorería del hockey del Jockey Club Córdoba.
Muestra la app web de Apps Script en pantalla completa, con el escudo como ícono.
Los datos viven en la planilla de tesorería; acá solo están la pantalla de carga y los íconos.

Para cambiar el link de la app, editar `APP_URL` en `index.html`.
